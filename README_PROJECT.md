# Student Performance Analysis

## Objective
Explore how study hours and attendance relate to students' academic scores using Python, Pandas, and Matplotlib.

## Dataset
`data/student_performance.csv` is a small **synthetic sample dataset created for practice**. It does not contain real student records.

## Questions explored
- What are the average Math, Reading, Writing, and Final scores?
- How do average final scores vary across study-hour groups?
- How do scores vary with attendance?

## Tools
- Python
- Pandas
- Matplotlib

## Run locally
1. Install Python.
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python student_performance_analysis.py`

The script prints summary statistics and saves charts in the `outputs` folder.
